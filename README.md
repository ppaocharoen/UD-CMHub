# UD-CM Hub — ระบบบริหารงานก่อสร้าง เทศบาลนครอุดรธานี

ระบบในเครือ UD ร่วมกับ [UD-Cost Hub](https://ppaocharoen.github.io/UDmaterial-price/) (ระบบข้อมูลราคางานก่อสร้าง)

S-Curve · BOQ (ปร.4) · แผนงาน / งวดงาน · ชิ้นส่วนโครงสร้าง · ติดตามเอกสาร · รายงานราชการ (ประจำวัน / ประจำสัปดาห์ / ภาพถ่าย / สรุป)

เปิดใช้งาน: **https://ppaocharoen.github.io/UD-CMHub/** (คู่มือฉบับเต็มอยู่ในระบบ ปุ่ม "คู่มือ" มุมขวาบน)

## ข้อมูลเก็บที่ไหน

- ข้อมูลโครงการ รูปภาพ และไฟล์แนบ เก็บในเบราว์เซอร์ของเครื่องที่ใช้งาน
- **คลาวด์ (ไม่บังคับ):** เข้าสู่ระบบด้วยบัญชี Google เพื่อซิงก์ *ข้อมูลข้อความ* ของโครงการระหว่างเครื่อง — รูปและไฟล์แนบไม่ขึ้นคลาวด์ แต่ละบัญชีเห็นเฉพาะข้อมูลของตัวเอง
- ล้างข้อมูลเบราว์เซอร์ = ข้อมูลในเครื่องหาย → ตั้ง **สำรอง/กู้คืน → ตั้งค่าสำรองอัตโนมัติ** ให้สำรองลงโฟลเดอร์ในเครื่องเสมอ

## ใช้งานคลาวด์ครั้งแรก

1. กด **เข้าสู่ระบบ** → เลือกบัญชี Google
2. กรอกชื่อ - นามสกุล ตำแหน่ง และหน่วยงาน → **ส่งคำขอใช้งาน**
3. รอผู้ดูแลระบบอนุมัติ (ระหว่างรอใช้งานในเครื่องได้ตามปกติ) แล้วกดปุ่มคลาวด์ → **ตรวจสถานะอีกครั้ง**

ผู้ดูแลระบบอนุมัติ / ไม่อนุมัติ / ระงับผู้ใช้ได้ที่ปุ่มคลาวด์ → **อนุมัติผู้ใช้งาน** (สิทธิ์บังคับที่ Firestore Rules ในไฟล์ `firestore.rules`)

## ย้ายข้อมูลจากไฟล์ .html เดิมในเครื่อง (ทำครั้งเดียว)

1. เปิดไฟล์ระบบเดิม → **สำรอง/กู้คืน → บันทึกไฟล์สำรองข้อมูล** (.json) และ **สำรองไฟล์แนบ+รูป (ZIP)**
2. เปิดเว็บไซต์ → **สำรอง/กู้คืน → นำเข้าไฟล์สำรองข้อมูล** (.json) แล้ว **นำเข้าไฟล์แนบ/รูป (ZIP)** หรือ **ตั้งค่าสำรองอัตโนมัติ → กู้คืนจากโฟลเดอร์สำรอง**
3. ตั้งสำรองอัตโนมัติบนเว็บอีกครั้ง (เลือกโฟลเดอร์เดิมได้)

ระบบตรวจรูปแบบข้อมูลทุกครั้งที่นำเข้า และไม่รับไฟล์ที่ถูกแก้ไขให้ผิดปกติ — รับไฟล์เฉพาะจากเพื่อนร่วมงานที่รู้จัก
