# UD-CM Hub — ระบบบริหารงานก่อสร้าง เทศบาลนครอุดรธานี

ระบบในเครือ UD ร่วมกับ [UD-Cost Hub](https://ppaocharoen.github.io/UDmaterial-price/) (ระบบข้อมูลราคางานก่อสร้าง)

S-Curve · BOQ (ปร.4) · แผนงาน/งวดงาน · ชิ้นส่วนโครงสร้าง · ติดตามเอกสาร · รายงานราชการ (ประจำวัน / ประจำสัปดาห์ / ภาพถ่าย)

เปิดใช้งาน: **https://ppaocharoen.github.io/UD-CMHub/**

## ข้อมูลเก็บที่ไหน

- ข้อมูลโครงการ รูปภาพ และไฟล์แนบ **เก็บในเบราว์เซอร์ของเครื่องที่ใช้งาน** ไม่ได้อยู่ในเว็บไซต์นี้ (ยกเว้นเลือกเข้าสู่ระบบเพื่อซิงก์ข้อมูลข้อความ — ดูด้านล่าง)
- คนอื่นที่เปิดลิงก์เดียวกันจะเห็นระบบว่าง ๆ ของตัวเอง ไม่เห็นข้อมูลของเรา
- ล้างข้อมูลเบราว์เซอร์ (cookies / site data) = ข้อมูลหาย → ตั้ง **💾 สำรอง/กู้คืน → 📁 ตั้งค่าสำรองอัตโนมัติ** ให้สำรองลงโฟลเดอร์ในเครื่องเสมอ
- **☁ เข้าสู่ระบบ (ไม่บังคับ):** ล็อกอินด้วยบัญชี Google แล้วข้อมูลข้อความของโครงการจะซิงก์ขึ้นคลาวด์ (Firebase, ศูนย์ข้อมูลกรุงเทพฯ) อัตโนมัติ — เปิดเครื่องอื่นแล้วล็อกอินก็เห็นโครงการเดิม · แต่ละบัญชีเห็นเฉพาะของตัวเอง · **รูปและไฟล์แนบไม่ขึ้นคลาวด์** ยังเก็บในเครื่องและสำรองลงโฟลเดอร์ตามเดิม

## ย้ายข้อมูลจากไฟล์ .html เดิมในเครื่อง (ทำครั้งเดียว)

เบราว์เซอร์แยกข้อมูลของ "ไฟล์ในเครื่อง" กับ "เว็บไซต์" ออกจากกัน เปิดเว็บครั้งแรกจึงยังว่าง

1. เปิดไฟล์ระบบเดิมในเครื่อง → **💾 สำรอง/กู้คืน → 💾 บันทึกไฟล์สำรองข้อมูล** (.json) และ **📎 สำรองไฟล์แนบ+รูป (ZIP)**
   (หรือถ้าตั้งสำรองอัตโนมัติลงโฟลเดอร์ไว้แล้ว ข้ามข้อนี้ได้)
2. เปิดเว็บไซต์ → **💾 สำรอง/กู้คืน → 📂 นำเข้าไฟล์สำรองข้อมูล** (.json) แล้ว **📥 นำเข้าไฟล์แนบ/รูป (ZIP)**
   หรือ **📁 ตั้งค่าสำรองอัตโนมัติ → กู้คืนจากโฟลเดอร์สำรอง**
3. ตั้ง **📁 สำรองอัตโนมัติ** บนเว็บอีกครั้ง (เลือกโฟลเดอร์เดิมได้)

## ติดตั้งเป็นแอป (ไม่บังคับ)

Microsoft Edge / Chrome: กดไอคอน "ติดตั้งแอป" ที่แถบที่อยู่ (หรือเมนู ⋯ → แอป → ติดตั้งไซต์นี้เป็นแอป) จะได้ไอคอนบนเดสก์ท็อป เปิดเป็นหน้าต่างแยก ข้อมูลชุดเดียวกับที่เปิดผ่านเว็บ

## อัปเดตเวอร์ชัน

อัปโหลด `index.html` ใหม่ทับไฟล์เดิมใน repository นี้ — ทุกคนที่เปิดลิงก์จะได้เวอร์ชันใหม่ (กด Ctrl+F5 ถ้ายังเห็นของเก่า) ข้อมูลในเครื่องไม่หาย
